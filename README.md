# Слово — игра-угадайка (Android TV и телефон, один APK)

Загадано слово из 5 букв, на угадывание даётся 5 попыток.
После каждой попытки буквы подсвечиваются:

- **зелёный** — буква на своём месте;
- **жёлтый** — буква есть в слове, но стоит в другом месте;
- **коричневый** — такой буквы в слове нет.

Одно и то же приложение работает и на Android TV, и на обычном телефоне:

- **Пульт ТВ:** стрелки двигают выбор по экранной клавиатуре, **OK** нажимает выбранную клавишу
  («Ввод» — отправить слово, «⌫» — стереть букву). Если подключена USB-клавиатура, можно печатать буквами.
- **Телефон:** буквы нажимаются пальцем — тап сразу печатает букву, слово и ряды сами подстраиваются
  под размер и поворот экрана.

При запуске приложение спрашивает, сколько будет играть:

- **Один игрок** — обычная игра, статистика побед сохраняется между запусками.
- **Два игрока** — поочерёдно вводятся имена (можно просто нажать «Ввод», тогда останутся имена
  по умолчанию), дальше игроки по очереди вводят слова на одном пульте/экране, кто первым
  угадает — тот и выиграл раунд. Табло над клавиатурой показывает счёт и подсвечивает, чей ход.

Дополнительные возможности:

- **Подсказка (💡)** — открывает следующую букву слова, но «съедает» одну попытку
  (одна из пяти строк становится недоступной и гаснет). Нельзя взять подсказку, если это
  оставит ноль попыток на отправку слова.
- **Голосовой ввод (🎤)** — открывает системное распознавание речи Android и подставляет
  сказанное слово целиком. Нужно разрешение на микрофон (приложение запросит его само при
  первом использовании). На части пультов кнопка микрофона перехватывается самим телевизором
  раньше, чем доходит до приложения, — в этом случае пользуйтесь экранной кнопкой «🎤».
  Эту часть я не могу проверить в своей среде (нет Android-устройства и SDK) — проверьте
  на реальном ТВ и напишите, если что-то работает не так.
- **Звук и анимация** — клик по клавише, перезвон при угадывании буквы, фанфары и конфетти
  при победе.

## Как собрать APK в облаке (GitHub Actions, без Android Studio)

Этот способ не нагружает ваш компьютер — вся сборка идёт на серверах GitHub.

1. Зайдите на [github.com](https://github.com) и создайте новый **пустой** репозиторий (без README, .gitignore и лицензии) — например, `slovo-tv`.
2. Загрузите в него содержимое этой папки одним из способов:
   - **Через браузер:** на странице нового репозитория нажмите «uploading an existing file» и перетащите туда всё содержимое папки `slovo-tv` (включая скрытую папку `.github` — если браузер её не показывает, см. способ ниже через git).
   - **Через git** (надёжнее, скрытые папки точно попадут):
     ```
     cd slovo-tv
     git init
     git add .
     git commit -m "Первая версия игры"
     git branch -M main
     git remote add origin https://github.com/<ваш-логин>/slovo-tv.git
     git push -u origin main
     ```
3. Откройте вкладку **Actions** в репозитории на GitHub — сборка запустится автоматически (или нажмите «Run workflow», если видите кнопку).
4. Через 2–5 минут сборка завершится зелёной галочкой. Откройте её, внизу страницы будет раздел **Artifacts** со ссылкой на `app-debug` — скачайте, внутри .zip лежит `app-debug.apk`.

Файл сборки лежит в `.github/workflows/build.yml` — его не нужно трогать, GitHub находит его сам.

## Как собрать APK локально (Android Studio)

1. Установите [Android Studio](https://developer.android.com/studio) (версия Koala 2024.1 или новее, JDK 17 идёт в комплекте).
2. `File → Open` и выберите эту папку (`slovo-tv`). Дождитесь окончания синхронизации Gradle
   (при первом открытии Studio сама скачает Gradle 8.7 и Android SDK 34).
3. `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

Если Studio ругается на отсутствие `gradle-wrapper.jar`, откройте
`File → Settings → Build, Execution, Deployment → Build Tools → Gradle` и выберите
*Gradle JDK: jbr-17* и *Use Gradle from: gradle-wrapper.properties file* (или «Specified location» с Gradle 8.7).

## Как установить на телевизор

**Вариант 1 — флешка.** Скопируйте `app-debug.apk` на флешку, вставьте в ТВ, откройте файл через файловый менеджер
(на Xiaomi TV — «Файлы»/«File Manager») и разрешите установку из неизвестных источников.

**Вариант 2 — ADB по сети.**
1. На ТВ: `Настройки → Об устройстве → Сборка` — нажмите OK 7 раз, чтобы включить режим разработчика.
2. `Настройки → Для разработчиков` — включите «Отладка по USB» / «ADB по сети».
3. На компьютере в одной сети с ТВ:
   ```
   adb connect <IP-адрес-ТВ>:5555
   adb install app-debug.apk
   ```

Приложение появится в списке приложений ТВ под названием «Слово».

## Структура

- `app/src/main/assets/index.html` — интерфейс и управление;
- `app/src/main/assets/game.js` — правила подсветки букв;
- `app/src/main/assets/words.js` — список слов (357 слов; чтобы добавить свои, дописывайте 5-буквенные слова в нижнем регистре, «ё» заменяйте на «е»);
- `app/src/main/java/com/example/slovo/MainActivity.java` — WebView на весь экран и передача кнопок пульта.

Открыв `index.html` в обычном браузере, можно проверить игру на компьютере.
